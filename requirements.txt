# OpenReel — Python dependencies
# ---------------------------------------------------------------------------
# Install into a PROJECT-LOCAL virtual environment (.venv) so nothing lands in
# your system Python. Same steps on Windows and macOS:
#
#   Windows (PowerShell):  python  -m venv .venv;  .venv\Scripts\Activate.ps1
#   macOS / Linux:         python3 -m venv .venv;  source .venv/bin/activate
#   Then (both):           pip install -r requirements.txt
#                          python -m spacy download en_core_web_sm
#
# This baseline runs 100% on CPU and behaves the same on Windows and macOS.
# It automatically uses an NVIDIA RTX GPU for transcription when CUDA is present.
# Optional higher-quality / GPU-only extras are listed at the bottom (commented)
# and documented in BLUEPRINT.md — install them only when you want them.
# ---------------------------------------------------------------------------
